# Sistema de Caixa Rumspringa — Versão 8.0 Professional

O **Sistema de Caixa Rumspringa** é um sistema completo de gerenciamento de vendas, estoque, clientes e fechamento de caixa desenvolvido especialmente para operações de conveniência, tabacaria e pequenos comércios que necessitam de um controle rápido, moderno e totalmente local.

O projeto foi construído com foco em:

* velocidade;
* estabilidade;
* segurança;
* facilidade de uso;
* funcionamento offline/local;
* independência de mensalidades ou serviços em nuvem.

## Objetivo do Projeto

O objetivo do Sistema de Caixa Rumspringa é oferecer uma solução profissional, moderna e extremamente funcional sem depender de servidores externos, mensalidades ou sistemas engessados.

Todo o sistema funciona localmente no navegador, proporcionando:

* velocidade;
* privacidade;
* controle total dos dados ;
* independência operacional.
