# Sistema-de-Caixa_Rumspringa-Conveniencia-v8.0_PRO-ULTIMATE
Um sistema completo e definitivo de controle de caixa, vendas e retiradas, totalmente local (sem nuvem), ideal para pequenos comércios, tabacarias, bares e conveniências. Desenvolvido para ser leve, rápido, seguro e funcional diretamente no navegador, com armazenamento automático via LocalStorage. Por Mr. Canatto. (v8.0)
